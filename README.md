# Color Scheme Designer (pal_cop)

Автономная, очищенная и улучшенная локальная версия приложения для подбора гармоничных цветовых палитр (деконструкция и развитие **Paletton.com** / *Color Scheme Designer*).

---

## Возможности

- **Перцептивное цветовое пространство OKLCH и Gamut Mapping**:
  - Математически точный перевод sRGB ↔ Linear sRGB ↔ OKLab ↔ OKLCH.
  - Честный Gamut Mapping бинарным поиском по Chroma ($C$) с сохранением светлоты ($L$) и оттенка ($H$) без грубого отсечения цветовых каналов.
  - Перцептивное смешивание и градиенты в OKLab без «грязной» середины.
  - **Универсальный ввод цвета**: поле Base Color принимает `oklch()`, `hsl()`, `rgb()` и HEX.
  - **EyeDropper API**: пипетка для захвата цвета с экрана (в браузерах с поддержкой).
- **Копирование цвета в один клик и селектор форматов**:
  - Переключатель формата на главной панели: **HEX**, **OKLCH**, **RGB**, **HSL** с сохранением выбора пользователя.
  - Клик по любому свотчу (основной цвет, 4 оттенка, вторичные, комплементарные цвета) мгновенно копирует цвет в буфер обмена в выбранном формате.
  - Всплывающее уведомление (toast) с подтверждением скопированного значения.
  - Анимация вспышки при клике (ripple/flash) и динамические подсказки при наведении.
  - Shift+клик или двойной клик по любому цвету открывает подробную карточку цвета (Color Info).
  - В карточке Color Info добавлен формат HSL, а клик по любому коду сразу копирует его.
- **Тональные шкалы (50…950)**:
  - Генерация современных 11-ступенчатых тональных шкал (50, 100, 200, 300, 400, 500, 600, 700, 800, 900, 950), как в Tailwind CSS и Material 3 HCT.
  - Естественный сдвиг оттенка (hue shift): светлые тона теплее, темные — глубже и холоднее.
  - Колоколообразная кривая насыщенности (chroma curve), предотвращающая вырождение цвета на крайних ступенях.
  - **Tonal Strip**: интерактивная полоска 11 свотчей для каждого оттенка прямо на главной панели с копированием в выбранном формате (HEX / OKLCH / RGB / HSL).
  - Полная таблица тональных шкал в диалоге Tables (вкладка «Tonal Scales») с копированием значений в один клик.
- **Современная оценка контраста (WCAG 2.2 и APCA)**:
  - **APCA ($L_c$)** — кандидат на стандарт доступности WCAG 3, учитывающий восприятие человеческим глазом в светлых и темных темах.
  - **WCAG AA (контраст ≥ 4.5:1)** — генерация палитры с гарантированным соответствием стандарту веб-доступности AA.
  - **WCAG AAA (контраст ≥ 7.0:1)** — генерация палитры повышенного контраста по стандарту AAA.
  - Просмотр точных значений `OKLCH` и `APCA Contrast` (на белом #FFF и черном #000 фоне) в карточке цвета (Color Info).
- **Расширенный цветовой движок и 15 дизайнерских профилей**:
  - **UI & Web**:
    - `SaaS UI`: технологичные индиго/синие/фиолетовые акценты с чистыми светлыми поверхностями.
    - `Minimal / Swiss`: швейцарский минимализм (графит, глубокий черный, чистый белый фон + 1 чистый акцент: швейцарский красный, кобальт или янтарь).
    - `Dark UI`: неоновые акценты повышенного контраста на темно-сером/черном фоне.
    - `Neutral + Pop`: нейтральная графитовая база с одним ярким комплементарным поп-акцентом.
  - **Aesthetics & Editorial**:
    - `Luxury`: премиальная палитра (черный оникс, слоновая кость/крем, шампань/золото, королевский бордо).
    - `Editorial`: журнальная теплая верстка с сильным типографическим контрастом.
    - `Retro`: теплые приглушенные оттенки 70-80-х годов с характером.
    - `Cyberpunk`: глубокий черный с неоновым цианом, маджентой и ядовитым лаймом.
  - **Nature & Mood**:
    - `Nature / Organic`: шалфейные и лесные зеленые, теплая терракота, песок, охра и глина.
    - `Pastel`: нежные зефирные тона (пудровый розовый, лавандовый, небесно-голубой, мятный).
    - `Playful`: солнечный желтый, коралловый, бирюзовый, фиолетовый с высокой энергетикой.
    - `Material / Earth`: кирпичный, теплая глина, хаки, крафтовые архитектурные тона.
    - `Ocean Marine`: глубокий navy, арктический циан, бирюза и кобальт.
    - `Sunset Twilight`: закатный коралл, теплый янтарь, сияющий оранжевый и сумеречная слива.
- **Режимы генерации и гармонии**:
  - Быстрый выбор режимов: **Split Complementary**, **Triadic**, **Tetradic**, **Monochromatic**, **Analogous**, **Double Complementary**.
  - Настроения: **Warm Mood** (генератор теплых тонов) и **Cool Mood** (генератор холодных тонов).
- **Умный рандомайзер и сохранение характера**:
  - **«Сохранить характер» (Keep Character)**: при повторной генерации вращает оттенки, но идеально сохраняет выверенную насыщенность, светлоту и визуальный темперамент палитры.
  - **«Вариации» (Variations)**: деликатный сдвиг оттенков ($\pm 10^\circ$) и микроподстройка насыщенности для поиска нюансов.
  - **Замок на цветах (Color Locks)**: фиксация Primary, Secondary и Complement при рандомизации.
  - **Глобальный шорткат**: пробел (`Space`) для мгновенной генерации новой палитры.
- **Интеллектуальная проверка и автокоррекция контраста (Fix Contrast)**:
  - Живой бейдж контраста в реальном времени с отображением фактического коэффициента (например, `Primary: 4.8:1 • Text: 8.4:1`) и статуса соответствия WCAG AA/AAA.
  - **Кнопка «Fix Contrast AA»**: автоматически подбирает и корректирует светлоту в OKLCH до достижения коэффициента $\ge 4.5:1$ без потери оттенка.
  - **Кнопка «Fix Contrast AAA»**: автоматическая подгонка под строгий стандарт $\ge 7.0:1$.
- **Избранное и история (Favorites & History)**:
  - Кнопка **«★ В избранное»** сохраняет понравившуюся палитру в `localStorage`.
  - Модальное окно **«★ Избранные палитры»** (доступно из диалога генератора и прямо из верхнего меню):
    - Визуальные карточки палитр с цветными мини-свотчами всех компонентов.
    - Применение палитры в 1 клик (`Load Palette`) с мгновенным обновлением рабочей области и URL-хеша.
    - Удаление палитр из сохраненных.
  - Автоматическое ведение истории последних сгенерированных палитр.
- **Классическая цветовая гармония (RYB)**: монохромная, смежная, триада, тетрада и свободный режим с комплементарными цветами.
- **Интерактивный цветовой круг**: вращение основного оттенка, настройка угла разброса вторичных цветов, точная подстройка (Fine Tune) яркости и насыщенности.
- **Симуляция нарушений зрения (Color Blindness)**: протанопия, дейтеранопия, тританопия, ахроматопсия и другие фильтры.
- **Живой UI Mockup**: мини-макет SaaS-интерфейса (navbar, сайдбар, карточки, форма, прогресс-бары, таблица) с семантическими ролями цветов (primary, secondary, complement, surface). Доступен в Preview → «UI Mockup». Цвета обновляются в реальном времени через CSS-переменные.
- **Интерактивные примеры (Examples)**: превью применения палитры на реальных макетах (веб-страницы в белой/черной/светлой/темной темах, орнаменты Tartan, Stripes, Blobs, Abstract, Flowers).
- **Экспорт палитры во все форматы**:
  - **Код**: HTML-страница палитры, CSS (Custom Properties + Utility Classes), LESS, SASS/SCSS, XML.
  - **Текст**: структурированный TXT-отчет с HEX и RGB значениями.
  - **Графика и софт**: изображение PNG (генерируется через Pillow), Photoshop Swatches (`.aco`), GIMP Palette (`.gpl`), палитра для Sketch (`.sketchpalette`).
  - **Figma Tokens / Variables**: файл `figma-tokens-{uid}.json`, совместимый с плагином **Tokens Studio for Figma** и нативными переменными Figma (Figma Native Variables).
  - **Векторный SVG (Figma / Illustrator)**: файл `paletton-{uid}.svg` с готовым векторным артбордом палитры (свотчи, HEX-метки и 11 ступеней тональных шкал), который можно просто скопировать или перетащить (drag-and-drop) в Figma.
  - **OKLCH CSS**: файл `palette.css` с переменными в `oklch()` (новый формат).
  - **Tailwind Config**: `tailwind.config.js` с тональными шкалами для Tailwind CSS v3.
  - **W3C DTCG Tokens**: `tokens.json` в формате Design Token Community Group (W3C).

- **Шеринг палитр**: поддержка коротких URL с `uid` (`/#uid=...` и `/palette.php?uid=...`).
- **Мультиязычность**: поддержка русского (`RU`), английского (`EN`) и чешского (`CS`) языков с мгновенным переключением.
- **Полная очистка и автономность**:
  - Удалены все рекламные блоки (DFP, Envato, Wix, TradeDoubler, AdBlock-нотификации, PayPal donate).
  - Удалены внешние трекеры (Google Tag Manager, Google Analytics).
  - Удален футер с устаревшей SEO-статьей и меню More Info с битыми внешними ссылками.
  - Снят доменный лок (приложение работает офлайн на `localhost`, `127.0.0.1` или любом другом хосте).
  - Проведён нейтральный ребрендинг (**Color Scheme Designer**).

## Установка и запуск

Для работы требуется **Python 3.8+** и библиотека **Pillow** (для экспорта палитры в PNG):

```bash
pip install pillow
```

Запуск локального сервера:

```bash
python3 server.py
# или с указанием произвольного порта:
python3 server.py 8080
```

После запуска перейдите в браузере по адресу:
👉 **`http://localhost:8000/`**

Сервер обеспечивает:
1. Раздачу всех статических файлов приложения (`HTML`, `JS`, `CSS`, изображения, превью-макеты).
2. Обработку запросов экспорта на `/export/index.php` во все форматы (HTML, CSS, LESS, SASS, XML, TXT, GPL, ACO, Sketch, PNG).
3. Обработку шеринг-ссылок вида `/palette.php?uid=...` с автопереходом на выбранную палитру.
